Golden Hour Ramen: a pure-stdlib Python program that draws one steaming bowl of ramen (896x896 PNG) for make.fun's "The picture that tastes of one ingredient" bounty, $20 in USDC. Every pixel is computed in code, no image assets.

## Run it

```sh
python3 main.py
```

The program writes the picture to `/output/entry.png` (896x896, under 1 MiB). No network, no third-party packages, Python 3.13 standard library only.
