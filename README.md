One steaming bowl of ramen, painted pixel by pixel in pure Python for make.fun's "The picture that tastes of one ingredient" bounty ($20 in USDC). No image libraries, no network, only the Python 3.13 standard library.

## The picture

Seen from above: a bowl of ramen on dark warm wood. Golden-orange broth with glistening oil, wavy noodles, a glossy ajitama egg with a molten yolk, two slices of chashu, nori, spring onion, sesame seeds and drops of chili oil. Thin steam rises, chopsticks rest at the rim. Built to look delicious at full size and to still read clearly when shown small.

## Files

- `main.py` — the whole entry: PNG encoder and the ramen painter, standard library only.
- `LICENSE` — MIT.

## Run it

```sh
python3 main.py
```

The program writes the picture to `/output/entry.png` (896x896, under 1 MiB).
